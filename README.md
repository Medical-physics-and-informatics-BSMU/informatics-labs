## Порядок выполнения

1. Выберите раздел и лабораторную работу.
2. Скачайте методические указания и шаблон отчёта.
3. Получите номер варианта у преподавателя и скачайте исходный файл.
4. Выполните задание, проверьте рекомендации ИИ и сдайте готовый документ и отчёт преподавателю.

## Безопасность

Все исходные данные вымышлены и не являются клиническими. ИИ используется для информационных, организационных и рутинных задач. Не передавайте персональные данные пациентов, медицинские документы и конфиденциальные сведения в общедоступные ИИ-сервисы. Проверяйте ответы ИИ. В рамках занятий ИИ не используется для постановки диагнозов или назначения лечения.
